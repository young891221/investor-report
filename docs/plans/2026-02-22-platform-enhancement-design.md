# 투자 리서치 플랫폼 + AI 어시스턴트 고도화 설계

> 작성일: 2026-02-22
> 상태: 설계 진행 중 (Phase 2 기능 구성까지 합의 완료)

## 1. 프로젝트 배경

### 현재 상태
- 바닐라 JS + GitHub Pages 정적 사이트
- 7개 종목의 상세 분석 리포트 (8개 섹션)
- Chart.js 차트, 다크 테마, V1/V2 템플릿 전환
- 종목 추가는 JSON 생성 스크립트로 자동화
- 수익화 기능 없음

### Pain Points
- 종목 수가 적음 (7개)
- 사용자 상호작용 부족 (읽기 전용)

### 목표
- 포트폴리오 고도화 우선, 수익은 부차적
- 일반 개인 투자자를 위한 투자 리서치 플랫폼 + AI 어시스턴트 구축

---

## 2. 선택된 접근 방식: A+B 혼합

3가지 접근 방식을 검토한 결과, **A(투자 리서치 플랫폼) + B(AI 투자 어시스턴트)** 혼합 방식을 채택.

### 검토한 방식들

| 방식 | 핵심 | 장점 | 단점 |
|------|------|------|------|
| A: 투자 리서치 플랫폼 | 콘텐츠 확대 + 사용자 참여 | 리텐션 높음, 확장성 좋음 | 개발 범위 넓음 |
| B: AI 투자 어시스턴트 | 대화형 AI 중심 차별화 | 차별화 강함, 임팩트 큼 | API 비용, 품질 관리 |
| C: 투자 커뮤니티 포털 | 소셜 기능, 네트워크 효과 | UGC, 네트워크 효과 | 초기 사용자 확보 어려움 |

### 채택 이유
1. Pain Point(종목 수 부족, 상호작용 부족)를 가장 직접적으로 해결
2. 기존 강점인 리포트 품질을 기반으로 확장
3. AI 어시스턴트로 차별화 확보
4. 향후 커뮤니티 기능(C) 점진적 추가 가능

## 3. 아키텍처

### 시스템 구성

```
[프론트엔드]                    [백엔드]                     [외부]
React/Next.js  ──────────>  Supabase                    Claude API
(Vercel 배포)               ├─ Auth (사용자 인증)         Yahoo Finance
                            ├─ PostgreSQL (DB)           SEC Edgar
                            ├─ Edge Functions
                            └─ Realtime (알림)
```

### 기술 스택 변경

| 영역 | 현재 | 변경 후 |
|------|------|---------|
| 프론트엔드 | 바닐라 JS | Next.js + TypeScript |
| 백엔드 | 없음 | Supabase (Auth, DB, Edge Functions, Realtime) |
| AI | 리포트 생성만 | Claude API (리포트 생성 + 챗봇) |
| 배포 | GitHub Pages | Vercel |
| 결제 | 없음 | 토스페이먼츠 또는 Stripe |

### 핵심 데이터 모델

- `users` - 사용자 프로필
- `stocks` - 종목 메타데이터
- `reports` - 분석 리포트 (기존 JSON 구조 유지)
- `watchlists` - 워치리스트
- `chat_sessions` - AI 대화 이력
- `subscriptions` - 구독 정보

## 4. 기능 상세 (Phase별)

### Phase 1 - 기반 마이그레이션 & 콘텐츠 확장

#### 1-1. Next.js 마이그레이션
- 기존 `index.html` → Next.js 페이지 구조 전환
- 기존 CSS 디자인 시스템 유지 (다크 테마)
- 기존 JSON 리포트 데이터 호환
- SEO 최적화 (메타태그, OG 이미지 자동 생성)

#### 1-2. 종목 분석 자동화 파이프라인
- Claude API를 이용한 리포트 자동 생성 강화
- 스케줄러로 기존 종목 리포트 주기적 업데이트 (주 1회)
- 종목 요청 대기열 시스템 (사용자가 원하는 종목 요청)
- 목표: 7개 → **50개+ 종목**으로 확대

#### 1-3. 종목 비교 기능
- 2-4개 종목을 나란히 비교하는 대시보드
- 재무 지표, 밸류에이션, 차트 오버레이
- URL 공유 가능 (예: `/compare?tickers=IREN,RKLB,CRWD`)

### Phase 2 - 사용자 기능

#### 2-1. 사용자 인증 & 프로필
- Supabase Auth (Google/GitHub 소셜 로그인)
- 투자 성향 프로필 (공격적/중립/보수적)

#### 2-2. 워치리스트 & 포트폴리오
- 관심 종목 워치리스트 (무제한)
- 보유 종목 포트폴리오 등록 (매수가, 수량)
- 포트폴리오 수익률 트래킹
- 섹터 배분 시각화

#### 2-3. 알림 시스템
- 워치리스트 종목 신규 리포트 발행 알림
- 투자 의견 변경 알림 (Buy → Hold 등)
- 이메일 + 브라우저 푸시 알림

### Phase 3 - AI 어시스턴트

#### 3-1. AI 챗봇
- 리포트 기반 Q&A ("IREN의 주요 리스크가 뭐야?")
- 자연어 종목 검색 ("사이버보안 섹터에서 Strong Buy인 종목")
- 포트폴리오 분석 ("내 포트폴리오 리스크 분석해줘")
- 시장 브리핑 요약

#### 3-2. AI 리포트 커스터마이징
- 사용자 투자 성향에 맞춘 리포트 하이라이트
- "나에게 맞는 종목 추천" 기능
