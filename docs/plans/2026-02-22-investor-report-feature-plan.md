# 투자 리포트 서비스 기능 중심 고도화 설계 (초보 투자자, 하이브리드 수익화)

## 요약
현재의 "리포트 열람형" 사이트를 `학습 + 실행 + 재방문`이 되는 투자 워크스페이스로 확장한다.
핵심은 `무료 기능으로 MAU 성장`을 만들고, 사용자가 자연스럽게 `유료 전환`하도록 업그레이드 경로를 설계하는 것이다.

목표 기준:
1. 6개월 내 MAU 10,000
2. 무료 유입-재방문 루프 구축
3. 하이브리드 수익화(광고/제휴 + 구독)

## 기능 설계 (우선순위별)

### 1) 무료 코어 기능 (성장 엔진)
1. 종목 탐색 고도화
- 기존 검색/필터 유지 + `초보자 필터` 추가
- 필터 예시: 변동성 낮음, 흑자 전환, 매출 성장, 리스크 낮음
- "오늘 많이 본 리포트", "이번 주 신규 리포트" 섹션

2. 리포트 이해 보조
- 각 섹션에 `초보자 해설` 토글
- 어려운 지표(PEG, FCF, ROE) 툴팁 + 3줄 설명
- "이 리포트 1분 요약" 카드 자동 생성

3. 개인 워치리스트
- 관심 종목 저장
- 리포트 업데이트 시 앱/이메일 알림(무료는 일 1회 digest)

4. 리포트 비교 뷰
- 최대 3종목 동시 비교
- 점수, 밸류에이션, 리스크, 촉매를 표준화 비교
- "초보자 추천 관찰 포인트" 자동 제시

5. 커뮤니티형 트래픽 장치
- 리포트 공유 이미지(OG) 자동 생성
- "내 워치리스트 공개 링크" 기능
- 댓글 대신 `반응형 피드백`(이해됨/어려움/관심있음)

### 2) 프리미엄 기능 (전환 엔진)
1. 프리미엄 알림
- 가격/점수/리포트 변경 조건 알림
- 종목별 맞춤 알림 룰 무제한

2. 포트폴리오 코치
- 보유 비중 입력 시 섹터 편중/변동성 경고
- "리밸런싱 제안" 시뮬레이션(권유가 아닌 시나리오)

3. 심화 리포트
- 월간 Deep Dive (산업 사이클, 경쟁구도, 밸류 시나리오)
- 리포트 히스토리 기반 "논리 변경 추적" 제공

4. 학습 모듈
- 초보자용 10분 투자 개념 코스
- 리포트 읽기 체크리스트 기반 진도/퀴즈

### 3) 수익화 기능
1. 광고
- 무료 사용자에만 노출
- 리포트 본문 방해 없는 위치(사이드/하단)
- 금융/교육 관련 브랜드만 허용

2. 제휴
- 증권사 계좌개설/ETF/도서/교육 제휴 링크
- 리포트 내 "관련 학습 리소스" 슬롯에 통합

3. 구독
- Free / Plus / Pro 3단
- 연간 구독 할인, 체험 7일
- 결제 실패/해지 복구 플로우 포함

## 사용자 흐름 설계
1. 유입
- 검색/공유 링크로 `종목 리포트` 진입
- 첫 방문에서 1분 요약 + 용어 해설로 이탈 방지

2. 활성화
- 워치리스트 3개 저장 유도
- 비교 뷰 1회 사용 유도
- 이메일/푸시 알림 옵트인 유도

3. 재방문
- 일간 digest + 주간 하이라이트
- 워치리스트 종목 업데이트 알림

4. 전환
- 알림 한도 도달/비교 횟수 제한 시 유료 제안
- "포트폴리오 코치 결과 저장" 기능을 paywall 포인트로 설정

## 정보 구조/화면 추가
1. 홈
- 기존 카드 그리드 유지
- 신규 섹션: 인기 리포트, 신규 리포트, 초보 추천 큐레이션

2. 종목 상세
- 기존 8개 섹션 유지
- 추가: 1분 요약, 초보자 해설 토글, 유사 종목 추천, 워치리스트 버튼

3. 비교 페이지 (`/compare`)
- 2~3종목 선택 비교
- 점수/밸류/리스크/촉매 4축

4. 내 페이지 (`/me`)
- 워치리스트
- 알림 규칙
- 포트폴리오 입력/코치 결과
- 구독 상태/결제 관리

## 공개 인터페이스/API/타입 변경 사항
1. 신규 API (예시)

- `POST /api/alerts/rules`
- `GET /api/compare?tickers=...`
- `POST /api/portfolio/analyze`
- `POST /api/billing/checkout`
- `POST /api/billing/webhook`

2. 데이터 스키마 추가
- `User`
- `WatchlistItem`
- `AlertRule`
- `PortfolioSnapshot`
- `Subscription`
- `EventLog` (조회/클릭/전환 추적)

3. 기존 리포트 데이터 확장
- `beginnerSummary` (1분 요약)
- `glossaryLinks` (용어 매핑)
- `relatedTickers`
- `changeLog` (리포트 논리 변경 기록)

## 비기능 요구사항
1. 성능
- 홈 LCP 2.5s 이하
- 종목 상세 첫 렌더 2.0s 이하
- 비교 페이지 3종목 기준 2.8s 이하

2. 신뢰/법적
- 전 페이지 투자 권유 아님 고지 유지
- 추천 문구는 "시나리오/정보 제공" 톤으로 제한
- 로그/결제 개인정보 최소 수집

3. 운영
- 이벤트 트래킹 표준화
- 관리자 대시보드: 리포트 조회수, 전환율, 이탈구간

## 테스트 및 검증 시나리오
1. 기능 테스트
- 워치리스트 추가/삭제/중복 방지
- 알림 룰 생성/수정/삭제
- 3종목 비교 정확성
- 구독 플랜 변경 및 권한 반영

2. 결제 테스트
- 결제 성공/실패/취소/환불
- 웹훅 재시도 및 중복 처리
- 만료 후 권한 회수

3. 데이터 테스트
- 리포트 확장 필드 스키마 검증
- 필수 지표 누락 시 graceful fallback
- 비교 지표 단위 정규화 검증

4. 성장 실험 테스트
- paywall 위치 A/B
- 알림 CTA 문구 A/B
- 무료 기능 제한 임계값 A/B

5. 수용 기준 (Acceptance)
- MAU 퍼널(유입→활성화→재방문) 대시보드 가동
- 무료→유료 전환 플로우 완주율 측정 가능
- 핵심 페이지 에러율 1% 미만

## 단계별 출시 계획
1. Phase 1 (4주): 성장 기반
- 워치리스트, 초보자 해설, 1분 요약, 공유 기능
- 이벤트 트래킹 구축

2. Phase 2 (4주): 전환 기반
- 비교 뷰, 알림 룰, Free/Plus paywall
- 결제/구독 기본 플로우

3. Phase 3 (4주): ARPU 개선
- 포트폴리오 코치, 심화 리포트
- 제휴 슬롯/광고 최적화

4. Phase 4 (지속): 최적화
- A/B 테스트 상시 운영
- 리텐션/전환 개선 반복

## 가정 및 기본값 (명시)
1. 웹 + 모바일 반응형 우선, 네이티브 앱은 범위 제외
2. 한국어 우선 서비스, 영어는 후순위
3. 초보 투자자 대상이므로 설명 UX를 핵심 KPI로 취급
4. 하이브리드 모델에서 초기 3개월은 `MAU 성장 > 매출 극대화`
5. 자동 매매/투자 자문 기능은 제공하지 않음
